# Règles du projet

Le dossier `rules/` regroupe toutes les règles du projet. Au début de chaque session, lis **tous** les fichiers `.md` de `rules/` et applique-les pendant toute la session, pour chaque ligne de code écrite, modifiée ou proposée.

@rules/README-SECURITE.md

En cas de conflit entre une demande et ces règles, signale le conflit avant d'agir.
Après chaque modification de code, termine par : règles concernées, ce qui a été fait, ce qui reste à vérifier.
